# 要求内容 — GitHub Actions 実行時間の削減

## 変更・追加する機能の説明

GitHub Actions の月間利用が 1,727 分（上限 2,000 分）に達しており、超過リスクがある。
実行時間を削減してコスト・リスクを解消する。

## ユーザーストーリー

- 1 回の実行を 10 分以内に収め、月間 600 分以下に抑えたい
- チャンネル追加・削除の運用フローは変えたくない
- 通知の正確性（重複なし・取りこぼしなし）は維持したい

## 受け入れ条件

- 547 チャンネルのフェッチが 3 分以内に完了する
- `notified.csv` の重複通知が発生しない
- Discord のレート制限（429）を適切にハンドリングする
- 異なる webhook へは並列で通知される

## 制約事項

- YouTube RSS / Discord Webhook の外部レート制限を守る
- stdlib のみで実装する（外部ライブラリ追加なし）
- channels.csv・app.yaml の構造を変更しない
